\rsection{Summary}
Physicist turned embedded systems engineer who works across the
hardware/software boundary.  Over ten years at Google building the sensor
platforms behind Street View: the IEEE~1588 time-synchronization stack,
lossless multi-10\,GbE capture data planes, and the MicroBlaze firmware and
bring-up tooling on the camera FPGAs.  Ph.D.\ in physics with first-author
papers in \emph{Nature Communications} and \emph{Optics Letters} and a
patented instrument.  Reads Verilog, probes boards, ships production C++,
and makes hardware debuggable by people and AI agents alike.

\secsp
\begin{list3}
\item[\lsection{Strengths}] {\bf Precision timing:} IEEE~1588 PTP, hardware
  timestamping, transparent clocks, clock modeling and interpolation (Kalman
  and RTS smoothing, PCHIP, integer-only FPGA arithmetic), PTP-scheduled
  triggering, TDEV and Allan-variance validation, TSN.
\item {\bf FPGA and embedded firmware:} AMD/Xilinx MicroBlaze on UltraScale+
  and Kintex, AXI peripherals, Vivado, JTAG and IBERT bring-up, POST,
  watchdogs, A/B flash update over quad-SPI; STM32, ESP32, AVR.
\item {\bf High-rate Linux data planes:} \texttt{PACKET\_RX\_RING}
  (TPACKET\_V3) with BPF, \texttt{SO\_TXTIME}, zero-copy shared memory,
  multi-10\,GbE capture; 10G PHYs, SFP+, MDIO Clause~45.
\item {\bf Hardware/software integration:} board bring-up, root-causing
  electrical faults, hardware-in-the-loop benches, Wireshark dissectors,
  Emboss binary-format code generation, Debian packaging.
\item {\bf AI-native engineering:} agentic coding workflows (Claude Code,
  Gemini CLI, Copilot agents), MCP tool servers, local LLM and Whisper
  inference on self-run GPU infrastructure.
\item {\bf Languages:} C, C++, Python, Bash (expert); TypeScript, MATLAB,
  Tcl, Lua, Starlark/Bazel, SQL, \LaTeX{} (experienced); Verilog (reading).
\end{list3}

\secsp
\begin{resitem}[2015--present]
\seclabel{Experience}{\bf Google LLC}, Mountain View, California\resdate\\
\textsl{Software Engineer, Geo Hardware (Street View sensor platforms).}
Contractor 2015, full-time from February 2016, promoted 2017, tech lead
since 2018.  Software lead on the previous-generation capture system;
embedded software lead for the FPGA team since 2024.
\begin{list3}
\item {\bf Time synchronization.}  Wrote the PTP synchronization stack and
  algorithms used across the team's current systems: an FPGA offset
  estimator in unsigned-integer arithmetic, an $n\log n$ local-to-global
  time interpolator, a clock interpolator designed for $\sigma<4$\,ns over
  four hours (min-RTT anchoring, PCHIP), and PTP-scheduled triggering for a
  seven-camera array.  Characterized clocks against a rubidium standard,
  Intel and Broadcom NICs, and PPS; offline oscillator analysis traced the
  cameras that kept failing to 5--10\,ppm drift and drove a better
  oscillator onto the board respin.
\item {\bf Capture data plane.}  Built the data plane, FPGA integration, and
  OS image of the previous-generation Street View capture system.  Designed
  the next platform's data plane: lossless capture of multiple saturated
  10\,GbE links via zero-copy \texttt{PACKET\_RX\_RING} and BPF, message
  reassembly, self-describing packet headers with hierarchical drop
  counters, picosecond-timestamped frames published over shared memory with
  multicast announcement, and a pktgen testbed simulating multiple 10G
  streams.
\item {\bf Camera FPGA firmware (2024--present).}  Own the MicroBlaze control
  plane of the next-generation vehicle camera: UDP command and logging,
  power-on self-test (DDR, PHY link, temperatures), watchdog, and A/B
  firmware upgrade over quad-SPI.  Shipping production firmware releases
  since early 2026; validated PTP against a reference grandmaster with TDEV.
\item {\bf Bring-up and root cause.}  Traced intermittent camera link
  failures to an under-specified crystal on the 10G PHY; found an AUX-board
  capacitor killing the UART; drove the 10G PHY mode decision with the
  silicon vendor's FAE; flagged an outsourced camera design as high risk
  early, before it was replaced by an in-house design.  Took on
  electrical-engineering work after a reorg: board rework, custom SFP
  modules, a relay-automated hardware-in-the-loop bench for camera batches.
\item {\bf Developer tooling.}  Built the team's camera bring-up and debug
  tool (C++ TUI and CLI over JTAG and UDP, self-test, bundled bitstreams,
  usage telemetry, Debian packaging), with an MCP interface for AI coding
  agents in development; Wireshark dissectors; Emboss-defined wire formats
  and register maps with generated C++ views.
\item {\bf Influence.}  Internal talks on timelines and PTP (2023) and on
  ``AI is the consumer'' and actionable visibility (2026); about a dozen
  technical interviews a month.
\end{list3}
\end{resitem}
